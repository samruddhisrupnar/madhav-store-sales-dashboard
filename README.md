# Madhav Store Online Sales Dashboard

##  Project Overview
This repository hosts an end-to-end Business Intelligence project developed in **Power BI** for **Madhav Store**. The primary objective of this project was to analyze multi-channel online sales data, transform raw transactional records into a structured data model, and design an interactive executive dashboard. The finalized solution tracks core Key Performance Indicators (KPIs), isolates sales trends, and uncovers actionable insights to optimize revenue and inventory strategies.

##  Tech Stack & Tools Used
* **Business Intelligence Tool:** Microsoft Power BI Desktop
* **Data Transformation (ETL):** Power Query Editor (Data Cleaning, Type Conversion, Filtering)
* **Data Modeling:** Star Schema, Table Relationships, Calculated Columns & DAX Measures
* **Visualizations:** Interactive Dashboards, Slicers, Card Visuals, Trend Charts

##  Key Responsibilities & Analytics Workflows

### 1. Requirements Gathering & KPI Identification
* Collaborated with business stakeholders to define reporting requirements and isolate target business metrics.
* Established critical sales performance measures and baseline KPIs to gauge annual growth.

### 2. ETL & Data Preparation
* Extracted and imported multi-table online sales datasets into Power BI.
* Utilized **Power Query** to clean missing entries, validate data types, handle exceptions, and transform raw rows into analytical tables.

### 3. Data Modeling & DAX Formulation
* Designed a clean, optimized data model by establishing exact relationships between transaction, customer, and product tables.
* Authored calculations and custom measures to support deep-dive performance analysis.

### 4. Interactive Dashboard Architecture
* Developed an executive-ready **Power BI Dashboard** combining modern UI design principles with user-friendly data mapping.
* Integrated dynamic slicers, filters, and cross-filtering charts allowing end-users to self-serve insights across dates, categories, and regions.

### 5. Insights Generation & Reporting
* Evaluated dashboard outputs to identify emerging seasonal trends, geographic performance variations, and high-value customer segments.
* Translated visual discoveries into executive summaries to directly support data-driven decision-making.
